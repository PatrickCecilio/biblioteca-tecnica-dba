lista os banco postgres
\l

Acessar o banco:
\c NOME_DO_BANCO

Ver schemas:
\dn

Todas (todos schemas):
\dt *.*

Só do public:
\dt public.*

psql -p 5432 -U postgres -c "SELECT
  t.spcname AS tablespace,
  pg_size_pretty(SUM(pg_total_relation_size(c.oid))) AS total_usado,
  SUM(pg_total_relation_size(c.oid)) AS total_bytes
FROM pg_class c
JOIN pg_tablespace t ON t.oid = c.reltablespace
WHERE t.spcname = 'sade_data'
GROUP BY t.spcname;
"

Verifique a versão do psql:
psql --version
