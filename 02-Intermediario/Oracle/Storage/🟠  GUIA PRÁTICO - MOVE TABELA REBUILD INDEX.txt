Comando executado:

4. CRIAÇÃO DA TABLESPACE AUXILIAR CCM_AUX_TBS
=============================================

Foi criada uma nova tablespace auxiliar para receber a tabela CCM_PROD.T1.

Comando executado:

create tablespace CCM_AUX_TBS
datafile '/u01/oradata/CDBPROD/PROD/ccm_aux_tbs01.dbf'

MAXSIZE UNLIMITED;

Resultado obtido:

Tablespace created.

Conclusão:

A tablespace CCM_AUX_TBS foi criada com sucesso.

===================================

status,

Conclusão:

A tablespace CCM_AUX_TBS estava ONLINE e configurada como PERMANENT.

==============================================================================
6. PRIMEIRA TENTATIVA DE MOVE DA TABELA
=======================================

Foi executado o comando para mover a tabela CCM_PROD.T1 para a tablespace CCM_AUX_TBS:

alter table CCM_PROD.t1
move tablespace CCM_AUX_TBS;

Erro apresentado:

ORA-01950: no privileges on tablespace 'CCM_AUX_TBS'

Causa:

O usuário CCM_PROD era o dono da tabela, porém ainda não possuía quota na tablespace de destino CCM_AUX_TBS.

Mesmo a operação sendo executada como SYSDBA, o Oracle exige que o usuário proprietário do segmento possua permissão de quota na tablespace onde o objeto será armazenado.

Conclusão:

Foi necessário conceder quota ao usuário CCM_PROD na tablespace CCM_AUX_TBS.

==============================================================================
7. CONCESSÃO DE QUOTA NA TABLESPACE CCM_AUX_TBS
===============================================

Foi concedida quota ilimitada ao usuário CCM_PROD na tablespace CCM_AUX_TBS.

Comando executado:

alter user CCM_PROD quota unlimited on CCM_AUX_TBS;

Resultado obtido:

User altered.

Conclusão:

O usuário CCM_PROD passou a ter permissão para alocar segmentos na tablespace CCM_AUX_TBS.

==============================================================================
8. MOVE DA TABELA CCM_PROD.T1 PARA CCM_AUX_TBS
==============================================

Após conceder a quota, o comando de move da tabela foi executado novamente.

Comando executado:

alter table CCM_PROD.t1
move tablespace CCM_AUX_TBS;

Resultado obtido:

Table altered.

Conclusão:

A tabela CCM_PROD.T1 foi movida com sucesso para a tablespace CCM_AUX_TBS.

==============================================================================
