==========================================
ATIVIDADE 1 - GMES Cold Backup (01:30 – 07:30)
==========================================

Objetivo: parar os bancos, executar backup frio e depois subir novamente.

1. Acesso aos servidores
   - Servidor 95 → su - orasvc11 (senha: <SENHA_USUARIO_ORACLE>)
   - Servidor 93 → su - orasvc21 (senha: <SENHA_USUARIO_ORACLE>)

2. Parar os bancos (shutdown immediate)
   Servidor 95:
     su - orasvc11
     . oraenv GMESAZP
     sqlplus / as sysdba
     SHUTDOWN IMMEDIATE;

   Servidor 93 (para cada SID):
     su - orasvc21
     . oraenv GSRMAZP
     sqlplus / as sysdba
     SHUTDOWN IMMEDIATE;

     . oraenv LMSAZP
     sqlplus / as sysdba
     SHUTDOWN IMMEDIATE;

     . oraenv GSPISAZ
     sqlplus / as sysdba
     SHUTDOWN IMMEDIATE;

     . oraenv AZLBPSP
     sqlplus / as sysdba
     SHUTDOWN IMMEDIATE;

3. Executar backup frio
   - Copiar datafiles, redo logs, controlfiles, parameter files para a área de backup.

4. Subir os bancos (startup + listener)
   Servidor 95:
     . oraenv GMESAZP
     sqlplus / as sysdba
     startup;
     lsnrctl start GMESAZP

   Servidor 93:
     . oraenv GSRMAZP
     sqlplus / as sysdba
     startup;
     lsnrctl start LI_GSRMAZP

     . oraenv LMSAZP
     sqlplus / as sysdba
     startup;
     lsnrctl start LI_LMSAZP

     . oraenv GSPISAZ
     sqlplus / as sysdba
     startup;
     lsnrctl start GSPISAZ

     . oraenv AZLBPSP
     sqlplus / as sysdba
     startup;
     lsnrctl start LI_AZLBPSP

5. Validação
   SELECT open_mode FROM v$database;


==========================================
ATIVIDADE 2 - Post-Perform Production Database Health-Check (13:00 – 14:00)
==========================================

Objetivo: verificar se os bancos subiram corretamente e se não há alertas/erros.

1. Processos Oracle
   select pid, spid, pname, program, tracefile
   from v$process
   where pname in ('PMON','DBW0','LGWR','SMON','CKPT','MMON','MMNL','RECO');

2. Listener
   ps -ef | grep tns
   lsnrctl status <NOME_LISTENER>

3. Erros (últimas 30h)
   select originating_timestamp, module_id, message_text
   from x$dbgalertext
   where originating_timestamp > systimestamp - 30
   and regexp_like(message_text, '(ORA-)');

4. Alertas pendentes
   select object_name, object_type, Reason, creation_time, time_suggested
   from dba_outstanding_alerts;

5. Jobs (DBMS e Scheduler)
   select job, LOG_USER, last_date, NEXT_DATE, broken, what
   from dba_jobs
   where last_date is not null
   order by last_date desc;

   select owner, job_name, enabled, last_start_date, next_run_date
   from dba_scheduler_jobs
   where owner not in ('SYS','SYSTEM','EXFSYS','ORACLE_OCM');

6. Integridade (Health Monitor)
   exec dbms_hm.run_check('DB Structure Integrity Check','regular-19-01');
   select DBMS_HM.GET_RUN_REPORT('regular-19-01') from dual;

   exec dbms_hm.run_check('Redo Integrity Check','redo-regular-19-01');
   select DBMS_HM.GET_RUN_REPORT('redo-regular-19-01') from dual;

   select * from V$DATABASE_BLOCK_CORRUPTION;
   select * from V$CORRUPT_XID_LIST;

7. Espaço e datafiles
   -- Espaço livre
   select nvl(b.tablespace_name, nvl(a.tablespace_name,'UNKOWN')) name,
          kbytes_alloc Mbytes,
          kbytes_alloc-nvl(kbytes_free,0) used,
          nvl(kbytes_free,0) free,
          ((kbytes_alloc-nvl(kbytes_free,0))/kbytes_alloc)*100 pct_used,
          nvl(largest,0) largest
   from (select sum(bytes)/1024/1024 Kbytes_free,
                max(bytes)/1024/1024 largest,
                tablespace_name
         from sys.dba_free_space group by tablespace_name) a,
        (select sum(bytes)/1024/1024 Kbytes_alloc,
                tablespace_name
         from sys.dba_data_files group by tablespace_name) b
   where a.tablespace_name (+) = b.tablespace_name
   order by 5 desc;

   -- Datafiles
   select file_name,file_id,tablespace_name,autoextensible,
          bytes/1024/1024 as SIZE_MB, online_status
   from dba_data_files
   order by online_status;

8. Objetos inválidos
   select owner, object_name, object_type, created, last_ddl_time, status
   from dba_objects
   where status ='INVALID'
   and last_ddl_time > sysdate -60;
