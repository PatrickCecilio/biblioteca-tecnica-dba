# GUIA PRÁTICO ORACLE

## Criação de Tabelas e Sequence para Ambiente de Teste

### 1. Criar tabela principal

```sql
CREATE TABLE <TABLE_NAME> (
    id          NUMBER GENERATED ALWAYS AS IDENTITY PRIMARY KEY,
    descricao   VARCHAR2(100) NOT NULL,
    endereco    VARCHAR2(150) UNIQUE,
    data_cadastro DATE DEFAULT SYSDATE
);
```

---

### 2. Criar Sequence

```sql
CREATE SEQUENCE <SEQUENCE_NAME>
START WITH 1
INCREMENT BY 1;
```

---

### 3. Criar tabela relacionada

```sql
CREATE TABLE <RELATED_TABLE_NAME> (
    id              NUMBER PRIMARY KEY,
    id_referencia   NUMBER,
    valor           NUMBER(10,2),
    data_cadastro   DATE DEFAULT SYSDATE
);
```

---

### 4. Validar as tabelas

```sql
SELECT table_name
FROM user_tables
WHERE table_name IN (
    UPPER('<TABLE_NAME>'),
    UPPER('<RELATED_TABLE_NAME>')
);
```

---

### 5. Validar a Sequence

```sql
SELECT sequence_name
FROM user_sequences
WHERE sequence_name = UPPER('<SEQUENCE_NAME>');
```
