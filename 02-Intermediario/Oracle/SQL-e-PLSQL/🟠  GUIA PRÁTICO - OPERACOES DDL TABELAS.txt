# GUIA PRÁTICO ORACLE

## Operações DDL em Tabelas

### 1. Criar uma tabela

```sql id="0zzl8m"
CREATE TABLE <TABLE_NAME> (
    id   NUMBER,
    nome VARCHAR2(50)
);
```

---

### 2. Adicionar uma nova coluna

```sql id="0s5n8g"
ALTER TABLE <TABLE_NAME>
ADD (
    descricao VARCHAR2(100)
);
```

---

### 3. Remover todos os registros da tabela

RISCO D3: TRUNCATE executa commit implícito; valide schema, objeto, backup,
dependências e quantidade de linhas. Faça esta etapa separada.

```sql id="7pkjll"
TRUNCATE TABLE <TABLE_NAME>;
```

---

### 4. Remover a tabela

RISCO D3: DROP remove definição e dados; confirme alvo e plano de retorno.

```sql id="0z0bpp"
DROP TABLE <TABLE_NAME>;
```
