# GUIA PRÁTICO ORACLE

## Criação de Usuário para Monitoramento Zabbix

### 1. Criar o usuário

```sql
CREATE USER "C##ZABBIX"
IDENTIFIED BY "<SENHA>"
DEFAULT TABLESPACE "USERS"
TEMPORARY TABLESPACE "TEMP"
PROFILE "<PROFILE>";
```

---

### 2. Conceder roles

```sql
GRANT "CONNECT" TO "C##ZABBIX";
```

```sql
GRANT "RESOURCE" TO "C##ZABBIX";
```

```sql
GRANT "SELECT_CATALOG_ROLE" TO "C##ZABBIX";
```

```sql
ALTER USER "C##ZABBIX" DEFAULT ROLE ALL;
```

---

### 3. Conceder CREATE SESSION

```sql
GRANT CREATE SESSION TO "C##ZABBIX";
```

---

### 4. Conceder acesso às views de monitoramento

GRANT SELECT ON "SYS"."V_$PGASTAT" TO "C##ZABBIX";

GRANT SELECT ON "SYS"."V_$LOG" TO "C##ZABBIX";
