Na sessao do ROOT, crie um script de inicialização customizado:
Crie um novo script que executará dbstart, lsnrctl start, e o comando SQL para abrir
o banco de dados (STARTUP)

º mkdir -p /opt/oracle/scripts

º sudo vi start_oracle.sh

# INICIO AQUI DO SCRIPT

#!/bin/bash
export ORACLE_HOME=/opt/oracle/product/23ai/dbhomeFree
export ORACLE_SID=FREE
export PATH=$ORACLE_HOME/bin:$PATH

# Iniciar banco de dados
$ORACLE_HOME/bin/dbstart $ORACLE_HOME

# Start listener
$ORACLE_HOME/bin/lsnrctl start

# Abrir banco de dados
echo "startup;" | $ORACLE_HOME/bin/sqlplus -s / as sysdba

# ATE AQUI


º cat /opt/oracle/scripts/start_oracle.sh

Torne o script executavel

º sudo chmod +x /opt/oracle/scripts/start_oracle.sh

VAMOS EDITAR O ARQUIVO PARA SUBIR O LISTENER DE FORMA AUTOMATICA E VAMOS INCLUIR OPCAO PARA SUBIR E ENCERRAR
O BANCO ORACLE DE FORMA AUTOMATICA, QUANDO O ORACLE LINUX FOR INICIALIZADO OU ENCERRADO.

º sudo vi /etc/systemd/system/oracle-listener.service

# COMECA AQUI O SCRIPT

[Unit]
Description=Oracle Database and Listener
After=network.target

[Service]
ExecStart=/bin/bash /opt/oracle/scripts/start_oracle.sh
ExecStop=/bin/bash -c '/opt/oracle/product/23ai/dbhomeFree/bin/lsnrctl stop && /opt/oracle/product/23ai/dbhomeFree/bin/dbshut /opt/oracle/product/23ai/dbhomeFree'
User=oracle
Group=oinstall
Restart=always
RestartSec=3
Type=forking
Environment="ORACLE_HOME=/opt/oracle/product/23ai/dbhomeFree"
Environment="ORACLE_SID=FREE"

[Install]
WantedBy=multi-user.target

# ATE AQUI

Configurar o oratab
Edite o arquivo /etc/oratab para garantir que o banco de dados seja iniciado automaticamente.
Cada linha neste arquivo corresponde a uma instância do banco de dados Oracle
e tem o formato: <ORACLE_SID>:<ORACLE_HOME>:N
