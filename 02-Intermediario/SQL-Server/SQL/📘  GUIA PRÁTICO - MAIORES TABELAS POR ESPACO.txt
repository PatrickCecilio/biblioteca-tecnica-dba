# GUIA PRÁTICO SQL SERVER

## Identificar as Maiores Tabelas por Espaço

### 1. Executar a consulta no banco desejado

```sql
SELECT
    t.name AS TableName,
    s.name AS SchemaName,
    p.rows,
    SUM(a.total_pages) * 8 / 1024 AS TotalSpaceMB
FROM sys.tables t
INNER JOIN sys.indexes i
    ON t.object_id = i.object_id
INNER JOIN sys.partitions p
    ON i.object_id = p.object_id
   AND i.index_id = p.index_id
INNER JOIN sys.allocation_units a
    ON p.partition_id = a.container_id
INNER JOIN sys.schemas s
    ON t.schema_id = s.schema_id
GROUP BY
    t.name,
    s.name,
    p.rows
ORDER BY TotalSpaceMB DESC;
```

---

### 2. Interpretar o resultado

A consulta retorna:

```text
TableName
SchemaName
rows
TotalSpaceMB
```

O resultado já será ordenado por `TotalSpaceMB DESC`, colocando as tabelas que mais ocupam espaço no início.
