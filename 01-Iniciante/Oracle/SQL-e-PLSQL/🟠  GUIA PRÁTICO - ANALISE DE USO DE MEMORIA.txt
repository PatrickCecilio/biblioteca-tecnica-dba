1. O que significa “db file sequential read”

O evento db file sequential read indica:

Leitura de um único bloco no disco.

Chamado normalmente por:
• índices
• table access by rowid
• nested loops
• full scans pequenos

Tipicamente ocorre quando:
• há muitas buscas por índice
• há queries mal otimizadas
• o buffer cache não está retendo os blocos
• há contenção ou latência no storage

Quando esse evento explode, o Oracle está esperando pelo disco.
