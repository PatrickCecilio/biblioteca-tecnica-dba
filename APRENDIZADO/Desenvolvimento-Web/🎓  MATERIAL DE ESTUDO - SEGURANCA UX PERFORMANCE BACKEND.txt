================================================================================
🔒 GUIA DE MELHORIAS – SEGURANÇA, UX, PERFORMANCE E BACK-END
================================================================================

📦 OBJETIVO
--------------------------------------------------------------------------------
Consolidar as principais áreas de melhoria do sistema (site/e-commerce) para
evoluir em segurança, usabilidade, desempenho e escalabilidade.

================================================================================
🔒 1. SEGURANÇA & INFRAESTRUTURA
================================================================================

🧱 Reforçar Content Security Policy (CSP)
  - Aplicar nonce em scripts críticos
  - Reduzir domínios liberados
  - Definir CSP distinta para páginas públicas x admin

🔐 HTTPS obrigatório
  - Redirecionar HTTP → HTTPS
  - Ativar HSTS (Strict-Transport-Security)

🧩 Headers de segurança
  - X-Content-Type-Options: nosniff
  - Referrer-Policy mais restritiva

🧠 Proteção de rotas administrativas
  - Validar em cada request se o usuário ainda possui papel de admin

📋 Logs de segurança
  - Registrar tentativas de login suspeitas
  - Logar acessos a rotas sensíveis (admin, upload etc.) com IP + user-agent

================================================================================
👤 2. AUTENTICAÇÃO, SESSÕES & CONTA
================================================================================

✅ Já implementado:
  - Sessão com Redis
  - Proteção anti brute-force
  - Refresh token funcional
  - Histórico de sessões por dispositivo

🚀 Melhorias sugeridas:
  - Página “Segurança da Conta” no perfil
      • Mostrar últimas tentativas de login (IP, sucesso/falha)
      • Botão “Encerrar todas as sessões”
  - Alerta de login em novo dispositivo (via e-mail)
  - Implementar 2FA (Google Authenticator ou e-mail)
  - Recuperação de senha robusta
      • Token de reset com expiração curta
      • Tela dedicada com validação forte

================================================================================
🛒 3. FUNCIONALIDADES DE E-COMMERCE
================================================================================

🖼️ Página de produto (PDP) aprimorada
  - Zoom na imagem
  - Variações: cor, tamanho, modelo
  - Avaliações (nota + comentário)
  - Botão “Comprar agora”

🚚 Frete por CEP
  - Integração com API (Correios/transportadora)
  - Cálculo dinâmico de prazo e valor
  - Simulação na PDP e no carrinho

🛍️ Checkout convidado + opções PIX/cartão
💖 Wishlist / Favoritos
  - Salvar itens no localStorage ou banco

🧠 Carrinho inteligente
  - Cupons e frete grátis por valor mínimo
  - Salvar no banco (recuperável em outro dispositivo)

================================================================================
🎨 4. UX / UI & NAVEGAÇÃO
================================================================================

📱 Responsividade mobile
  - Revisar fluxos: login, cadastro, carrinho, perfil
  - Aumentar área de toque de botões e ícones

📌 Sticky Elements
  - Botão fixo “Ver carrinho” no mobile
  - Header fixo com logo e ícones principais

💬 Feedbacks mais claros
  - Mensagens amigáveis (“Ops, esse e-mail já existe 💅”)
  - Loading states melhores (spinners/skeletons)

♿ Acessibilidade
  - Foco visível, contraste adequado
  - aria-label, role e alt em imagens importantes
