# GUIA PRÁTICO ORACLE

## Limpeza de Alert, Incident e Trace — Grid/Listener (D3)

RISCO D3: PURGE remove diagnósticos e pode eliminar evidências.

Use o ADRCI e selecione apenas o ADR home do listener validado. Confirme
incidentes em aberto, retenção aprovada e coleta de suporte. Consulte o
RUNBOOK-LIMPEZA-DIAGNOSTICOS.md antes da execução. -AGE usa minutos.

### 1. Limpar arquivos XML do Alert

```bash
adrci
SHOW HOMES
SET HOMEPATH <LISTENER_ADR_HOME_VALIDADO>
SHOW CONTROL
```

---

### 2. Limpar arquivos de Incident

```bash
Não apague incidentes ativos. Preserve evidências antes de PURGE.
```

---

### 3. Limpar arquivos de Trace

```bash
Após aprovação, use ADRCI PURGE -AGE <MINUTOS_APROVADOS> -TYPE TRACE
para um único ADR home. Valide o espaço e os diagnósticos depois.
```
