# GUIA PRÁTICO ORACLE

## Limpeza de backups RMAN — D3

Não remova peças de backup com `find -exec rm`. A idade do arquivo no
filesystem não determina se ele ainda é necessário para recuperação.
Use o procedimento RMAN em
`03-Avancado/Oracle/Backup-Recovery/💾  GUIA PRÁTICO - LIMPEZA BACKUPS RMAN FILESYSTEM.txt`.

### 1. Validar backups de Archive antigos

```bash
find <RMAN_ARCHIVE_PATH> \
-name "*.bkp" \
-mtime +<RETENTION_DAYS>
```

---

### 2. Inspecionar no RMAN antes de qualquer exclusão

```bash
rman target /
SHOW RETENTION POLICY;
LIST BACKUP SUMMARY;
REPORT OBSOLETE;
```

---

### 3. Validar backups de Database antigos

```bash
find <RMAN_DATABASE_PATH> \
-name "*.bkp" \
-mtime +<RETENTION_DAYS>
```

---

### 4. Execução controlada

```bash
Após revisar a política, a lista e os backups necessários, executar
DELETE OBSOLETE com prompt e aprovação operacional no RMAN.
```

---

### 5. Validar novamente após a limpeza

```bash
find <RMAN_ARCHIVE_PATH> \
-name "*.bkp" \
-mtime +<RETENTION_DAYS>
```

```bash
find <RMAN_DATABASE_PATH> \
-name "*.bkp" \
-mtime +<RETENTION_DAYS>
```

---

### 6. Verificar espaço disponível

```bash
df -h
```
