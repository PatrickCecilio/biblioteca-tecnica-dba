RISCO D3 — habilitar Flashback exige parada e espaço na FRA; restore point
garantido pode consumir a FRA. Confirme banco, janela, backup restaurável,
archivelogs, espaço e RPO/RTO. Execute cada etapa após validar o estado.

sqlplus / as sysdba

SELECT log_mode, flashback_on, open_mode
FROM v$database;

SHOW PARAMETER db_recovery_file_dest;

SHOW PARAMETER db_recovery_file_dest_size;

SHUTDOWN IMMEDIATE;

STARTUP MOUNT;

ALTER DATABASE FLASHBACK ON;

ALTER DATABASE OPEN;

CREATE RESTORE POINT <RESTORE_POINT_NAME> GUARANTEE FLASHBACK DATABASE;

SELECT name, scn, time, guarantee_flashback_database
FROM v$restore_point
ORDER BY time DESC;

EXIT;
