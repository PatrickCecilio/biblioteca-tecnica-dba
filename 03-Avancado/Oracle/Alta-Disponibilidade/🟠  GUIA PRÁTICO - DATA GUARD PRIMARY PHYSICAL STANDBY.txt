## Etapa 6

**Objetivo**

Dimensionar e criar Standby Redo Logs no Primary.

**Comandos**

```sql
SELECT
    thread#,
    group#,
    bytes/1024/1024 AS size_mb
FROM v$log
ORDER BY thread#, group#;
```

```sql
SELECT
    thread#,
    COUNT(*) AS online_groups,
    MAX(bytes)/1024/1024 AS max_size_mb
FROM v$log
GROUP BY thread#;
```

Criar pelo menos:

```text
ONLINE REDO GROUPS POR THREAD + 1
```

```sql
ALTER DATABASE ADD STANDBY LOGFILE
THREAD <THREAD_NUMBER>
GROUP <SRL_GROUP_NUMBER>
'<PRIMARY_SRL_PATH>'
SIZE <SRL_SIZE>;
```

Repetir para todos os grupos necessários.

**Validação**

```sql
SELECT
    group#,
    thread#,
    bytes/1024/1024 AS size_mb,
    status
FROM v$standby_log
ORDER BY thread#, group#;
```

## Etapa 18

**Objetivo**

Criar o Physical Standby via Active Duplicate.

**Comandos**

```rman
DUPLICATE TARGET DATABASE
FOR STANDBY
FROM ACTIVE DATABASE
DORECOVER
SPFILE

  SET db_unique_name='<STANDBY_DB_UNIQUE_NAME>'

  SET log_archive_config=
      'DG_CONFIG=(<PRIMARY_DB_UNIQUE_NAME>,<STANDBY_DB_UNIQUE_NAME>)'

  SET log_archive_dest_1=
      'LOCATION=<STANDBY_ARCHIVE_PATH>
       VALID_FOR=(ALL_LOGFILES,ALL_ROLES)
       DB_UNIQUE_NAME=<STANDBY_DB_UNIQUE_NAME>'

  SET log_archive_dest_2=
      'SERVICE=<PRIMARY_TNS>
       ASYNC
       VALID_FOR=(ONLINE_LOGFILES,PRIMARY_ROLE)
       DB_UNIQUE_NAME=<PRIMARY_DB_UNIQUE_NAME>'

  SET fal_server='<PRIMARY_TNS>'

  SET standby_file_management='AUTO'

  SET log_archive_format='%t_%s_%r.arc'

  SET control_files=
      '<STANDBY_CONTROLFILE_01>',
      '<STANDBY_CONTROLFILE_02>'

  SET db_file_name_convert=
      '<PRIMARY_DATA_PATH>',
      '<STANDBY_DATA_PATH>'

  SET log_file_name_convert=
      '<PRIMARY_REDO_PATH>',
      '<STANDBY_REDO_PATH>'

NOFILENAMECHECK;
```

**Observação**

`NOFILENAMECHECK` deve ser utilizado apenas quando Primary e Standby estão em hosts diferentes. Nunca utilizá-lo em duplicação no mesmo host quando houver risco de sobrescrever arquivos.
