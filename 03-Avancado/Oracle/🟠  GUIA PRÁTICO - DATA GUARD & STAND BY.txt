º sqlplus sys as sysdba

º SHUTDOWN IMMEDIATE;

º STARTUP MOUNT;

º ALTER DATABASE ARCHIVELOG;

º ALTER DATABASE FORCE LOGGING;

º ALTER DATABASE OPEN;

º ALTER SYSTEM SET DB_UNIQUE_NAME='PRIMARIO' SCOPE=SPFILE;

º ALTER SYSTEM SET LOG_ARCHIVE_CONFIG='DG_CONFIG=(PRIMARIO,STANDBY)' SCOPE=SPFILE;

º ALTER SYSTEM SET LOG_ARCHIVE_DEST_1='LOCATION=/u01/oracle/archivelogs VALID_FOR=(ONLINE_LOGFILES,PRIMARY_ROLE) DB_UNIQUE_NAME=PRIMARIO' SCOPE=SPFILE;

º ALTER SYSTEM SET LOG_ARCHIVE_DEST_2='SERVICE=STANDBY ASYNC VALID_FOR=(ONLINE_LOGFILES,PRIMARY_ROLE) DB_UNIQUE_NAME=STANDBY' SCOPE=SPFILE;

º ALTER SYSTEM SET FAL_SERVER=STANDBY SCOPE=SPFILE;

º ALTER SYSTEM SET FAL_CLIENT=PRIMARIO SCOPE=SPFILE;

Verifique o modo de FORCE LOGGING:
º SELECT FORCE_LOGGING FROM V$DATABASE;
A saída deverá indicar que o FORCE_LOGGING está ativado.

Criação dos Standby Redo Logs

º SELECT group#, members, bytes/1024/1024 AS size_mb FROM v$log;

Crie os grupos de standby redo logs:

º ALTER DATABASE ADD STANDBY LOGFILE GROUP 4 ('/u01/oracle/redo/standby_redo4.log') SIZE 50M;

º ALTER DATABASE ADD STANDBY LOGFILE GROUP 5 ('/u01/oracle/redo/standby_redo5.log') SIZE 50M;

º ALTER DATABASE ADD STANDBY LOGFILE GROUP 6 ('/u01/oracle/redo/standby_redo6.log') SIZE 50M;

Forçar a escrita dos logs:
